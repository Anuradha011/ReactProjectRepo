# React Projects 🚀

This repository contains my React.js learning projects and practice work.

I am building these projects step by step to understand the fundamentals of React, including components, props, JSX, CSS, reusable UI elements, and project structure.

---

## 📂 Projects

### 01-folder
A beginner-level React project created to understand the basic structure of a React application.

**Concepts covered:**
- React project structure
- JSX
- Components
- Basic styling
- React application setup

---

### 02-component
This project focuses on understanding **React Components** and how they are used to create reusable parts of a user interface.

**Concepts covered:**
- Functional Components
- JSX
- Component structure
- Reusable components
- Import and export
- CSS styling

---

### 03-props
This project focuses on understanding **Props in React**.

Props allow data to be passed from a parent component to a child component.

**Concepts covered:**
- Props
- Passing data between components
- Reusable components
- Dynamic content
- Component-based design

---

### 04-cards-project
A React card-based project created to practice reusable components and displaying data dynamically.

**Concepts covered:**
- Reusable components
- Props
- Card components
- JSX
- CSS styling
- Component composition
- Dynamic UI
